## 运行示例

### 1. 基本用法示例

这个示例演示 ai00-run 库的基本功能：

```bash
# 进入基本用法示例目录
cd examples/basic-usage

# 运行示例
cargo run --release
```

**功能包括：**
- 库初始化
- Node.js 环境管理
- Python 环境管理  
- 基本脚本执行
- 环境检查

- **Node.js**: 版本检测、路径管理、环境检查

### 脚本执行
- **Node.js 脚本**: 支持参数传递、版本指定
- **Python 脚本**: 支持虚拟环境、版本控制

- **环境健康检查**: 运行时环境验证

- **优雅的错误恢复**: 多脚本回退机制

## 开发说明

### 添加新示例

1. 在 `examples/` 目录下创建新项目
2. 添加 `Cargo.toml` 文件，依赖 ai00-run 库
3. 实现示例代码
4. 更新此 README 文档

### 测试建议

- 运行示例前确保系统已安装 Node.js 和 Python
- 使用 `--release` 标志以获得最佳性能
- 检查控制台输出以验证功能正常

## 故障排除

### 常见问题

1. **Node.js/Python 未找到**
   - 确保系统已安装相应运行时
   - 检查环境变量 PATH 设置

2. **权限错误**
   - 确保有执行脚本的权限
   - 在管理员模式下运行（如果需要）

3. **依赖错误**
   - 运行 `cargo clean` 清除缓存
   - 重新构建项目

### 调试技巧

- 启用详细日志输出
- 检查脚本文件路径是否正确
- 验证运行时版本兼容性
